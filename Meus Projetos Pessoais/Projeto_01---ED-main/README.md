Este projeto implementa em Python um sistema de fila de pacientes utilizando listas duplamente encadeadas, simulando o atendimento em clínicas ou hospitais. Cada paciente pode ser normal (N) ou prioritário (P), e a lógica garante que os prioritários tenham preferência sem excluir o atendimento dos normais. A fila é exibida no terminal de forma gráfica com caracteres ASCII, no formato `[ Nome (P/N) ] --> [ Nome (P/N) ]`, e também pode ser visualizada de forma invertida.
O programa inicia automaticamente com 10 pacientes já cadastrados, alternando entre normais e prioritários, permitindo observar a organização da fila. Também há exemplos práticos de inclusão, alteração e remoção de registros, demonstrando as principais operações da estrutura.
Como recurso extra, foi criado um modo interativo no qual o usuário pode digitar comandos como `add Nome Idade P/N` para incluir pacientes, `assist` para atender e remover, `edit Nome NovoNome NovaIdade P/N` para alterar dados, além de `exit`. Isso torna a aplicação mais prática e dinâmica para testes, mostrando como conceitos de estruturas de dados podem ser aplicados em situações reais.
